## Detailed Defect Fixes & Architectural Milestones (`v7.0` → `v8.3`)

### 1. `v7.1` & `v8.2` Native Synopsys Verdi `nWave` Signal-Population & Fail-Closed Fixes
- **Symptom (`DEF-V82-01`)**: `build_defect_d_safe_tcl_wrapper()` previously interpolated signal names inside double quotes (`puts "ENGR852_SIGNAL_ADDED ... sig={sp}"`), causing Tcl to interpret bus slice `[12:0]` in `count[12:0]` as a command call (`TclPlay: invalid command name "12:0", error line=41`), aborting `<nWave:4>` after only 3 signals.
- **Fix**: Each signal path is now assigned in braces (`set sig_path {{{sp}}}`) and referenced as `$sig_path` inside `wvAddSignal` and `puts`; `source` calls are guarded in `catch`; `_Verdi_1` is initialized safely. All **17/17 signals** in `fig10` execute cleanly (`rc=0`, `ENGR852_NWAVE_VERIFIED win=_nWave4 added=17 failed=0`).
- **Fail-Closed Verification (`DEF-V82-02`, `DEF-V82-03`)**: `build_signal_verification_records()` rejects empty or truncated logs (`added_ok=False`, `verified_nwave_handle="UNVERIFIED"`), and `launch(attach_existing=True)` checks `_find_verified_process_log_for_window()` before reusing any open X11 window (`0xe00006`).

### 2. `v8.3` Orderly Lifecycle State Machine, `.rc` Preservation & Modal Resolution
- **Root Cause**: Synopsys Verdi `novas.rc` defaults (`resaveSignals = TRUE`, `confirmExit = TRUE`) caused `"Remember to save signals to a signal file. Do you want to continue?"` (`"Question"` dialog X11 windows `0xe0063a`, `0xe0066f`) when switching or closing tabs.
- **Fix**: [`practice_from_scratch/scripts/engr852_verdi_lifecycle_manager.py`](practice_from_scratch/scripts/engr852_verdi_lifecycle_manager.py) writes per-job `.rc` files via `wvSaveSignal -win $target_w $engr852_rc_file`, tracks monotonic `selection_generation_id` (`native_selection_generation.json`), dismisses only job-owned modals via X11 `WM_DELETE_WINDOW`, and executes `execute_10_step_orderly_cleanup()` with zero broad `pkill`/`killall` calls.

### 3. `v8.0` → `v8.3` Security, Multi-Tenant Isolation & Stability Hardening
- **Sandboxed Open-Source EDA (`v8.0` / `v8.0.1`)**: Runs `iverilog` + `vvp` + `Yosys` under macOS Seatbelt / restricted execution, blocking unsafe `$system` calls and leaking files outside `0700` per-user sandboxes (`practice_from_scratch/v8_sandboxes/`).
- **Durable Async Jobs & Circuit Breaker (`v8.2`)**: `POST /api/v1/native-jobs` returns `202 Accepted` in `<50 ms`; `NetworkHealthAgent` protects university SSH (`:22`) with `CLOSED`/`HALF_OPEN`/`OPEN` states and `10s -> 20s -> 40s -> 60s` exponential backoff.
- **SQLite State Sanitization for Public Release**: Live session tokens (`sessions` table: 83 ephemeral tokens) were cleared and vacuumed (`sessions: 0`) prior to publishing [`practice_from_scratch/state_store/junior_developer_v8.sqlite3`](practice_from_scratch/state_store/junior_developer_v8.sqlite3) so seeded curriculum courses, lessons, and demo community structure remain inspectable with zero active session leakage.
